# Cloudflare Workers deployment

This frontend is configured to deploy to Cloudflare Workers using the OpenNext adapter.

## Required environment variables

Set these in Cloudflare Workers Builds or in your Worker environment:

- `NEXT_PUBLIC_API_BASE_URL`
- `NEXT_PUBLIC_API_URL` (optional alternative)
- `INTERNAL_API_BASE_URL` (optional server-side override)

For local preview you can put them in `.dev.vars`.

## Commands

- `npm run preview` - build with OpenNext and preview locally on the Workers runtime
- `npm run deploy` - build and deploy to Cloudflare Workers
- `npm run upload` - build and upload a new Worker version

## Notes

- Do not point Wrangler `main` at a Next page file.
- The Worker entrypoint is generated by OpenNext at `.open-next/worker.js`.
- Static assets are served from `.open-next/assets`.
